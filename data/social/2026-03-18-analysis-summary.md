### What worked on IG

Best carousel first lines:
- `Vers 1975, Centre-Ville (Ville-Marie) 🏙️`
- `Vers 1971, Boulevard Décarie (Côte-des-Neiges) 🛣️`
- `1928, Avenue du Mont-Royal (Vue vers l'est depuis Papineau) 🚋`
- `Vers 1969, Parc Kent (aujourd’hui Parc Martin‑Luther‑King Jr.) 🏃‍♂️🏊‍♀️`

Pattern:
- exact place first
- then date/era
- then neighborhood anchor
- then one concrete “what you’re looking at” explanation

IG carousel winners are not mystery-first. They are:
- place-legible
- date-legible
- immediately educational
- anchored in a visible detail or before/after clue

Best IG reels still used stronger curiosity hooks:
- `1972: Montreal said “let’s build a highway” 🚗`
- `What IS this thing? 🤔`
- `This building has a secret 👀`
- `Where legends were made... and then erased.`

But even the strongest IG reels underperformed the strongest carousels on average.

### What worked on FB

Best Facebook reel hooks:
- `70,000 morts dorment sous ce parc. 💀`
- `Rue Saint-Jacques, un rewind dans le Vieux-Montréal. 🕵️‍♀️`
- `Saint-Hubert, 1937: un voyage dans le temps. 🕰️`
- `Montréal cachait un Grand Canyon en plein Saint-Michel.`
- `Une rue fantôme.`
- `Ce marché a été sacrifié pour sauver Montréal. 🏚️`

Pattern:
- big first-line hook
- strong stakes immediately
- loss, erasure, hidden history, or shock
- Montreal-specific second beat
- informal/local tone helps

FB winners are more sensational than IG winners, but still work best when the reveal is tied quickly to a specific Montreal place.

## Cross-platform conclusions

### Instagram
Optimize for:
- carousel first
- place + date + neighborhood in line 1
- one concrete visible detail in paragraph 2
- one “what changed / what survived” beat
- archivist voice, not noir narrator

### Facebook
Optimize for:
- reel first
- first frame must function as thumbnail + hook
- high-stakes phrasing is acceptable if source-grounded
- strongest themes: erased history, sacrifice, disappearance, hidden layer
- keep Montreal anchor visible within the first beat

## Implication for the pipeline

The current automated system should not use one shared public voice for both platforms.

It should split into:
- `IG static/carousel`: archivist-teacher mode
- `FB reels`: hook-first urban-history mode

Shared research can stay unified, but platform narration should diverge.
