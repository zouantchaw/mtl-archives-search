# Specimen walkthrough and exact proposal test

Use the #73 City Memory Study 001 package when available. Expected upstream locations are under `docs/city-memory-study-001/`; this issue does not recreate or alter those artifacts.

## Fixed walkthrough (8–10 minutes)

1. **Outcome first (60 seconds):** show the title/thesis and one spatial application. Ask what decision this could help them make.
2. **Curated set (2 minutes):** show the selected direction and image relationships. Ask what feels specific to Montreal and what feels generic.
3. **Evidence boundary (2 minutes):** open one image’s provenance entry: canonical ID, archive/source reference, rights/license, attribution, observed facts, bounded metadata claims, uncertainty, and transform history. Ask what would need to be defensible internally.
4. **Use in place (2 minutes):** show the realistic spatial application and format/installation assumptions. Ask what they would need to approve production.
5. **Optional trust layer (1 minute):** show the interactive study or process appendix only after the output. Ask whether it changes confidence or visitor/guest value.
6. **Decision recap (1–2 minutes):** repeat the problem they named and ask whether this specimen changes the decision.

Stop and mark an objection if the package contains a weak image, unsupported historical claim, unclear right, or mockup that overpromises achievable quality. Never smooth over a rights or evidence boundary during the interview.

## Proposal to read verbatim

Read the `offer_text` field in the canonical [proposal.v1.json](./proposal.v1.json) verbatim. The ledger and validator bind every tested response to its proposal ID and SHA-256 digest (`048e71dff45a9d01e3f9a3f173c9a1cdc61f9957567b67980dd7ac803301f93a`), so scope, price, timeline, payment schedule, and exclusions cannot silently drift.

## Acceptance signal

Log one strongest signal per conversation: `interest_only` (opinion or enthusiasm), `written_yes` (explicit written approval to proceed at this scope/price), `signed_sow`, `procurement_started`, `paid_deposit`, or `declined`. A request for a scope, an introduction, or a follow-up is buyer intent only when tied to a dated action and the fixed proposal; it is not payment.
